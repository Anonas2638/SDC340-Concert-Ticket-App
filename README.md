## Project Description
Concert Ticket Hub is an Android mobile application developed
using Kotlin and Android Studio. The application allows users
to select a music festival, enter the number of tickets,
and calculate the total ticket cost.

## Application Features
- Custom concert ticket launcher icon
- Custom concert ticket image
- Spinner populated using a string array
- Numeric ticket quantity input
- Input validation
- Button click event handling
- Formatted total cost
- Single-screen user interface
